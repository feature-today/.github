# feature-today

> Platform to promote, prioritize and ship the features your users actually want.

## Projects

| Repo                                                       | Purpose                                                          |
| ---------------------------------------------------------- | ---------------------------------------------------------------- |
| [`.dev`](https://github.com/feature-today/.dev)            | Orchestration workspace + DevContainer + canonical AI rules      |
| [`.github`](https://github.com/feature-today/.github)      | Org-wide GitHub config + reusable workflows                      |
| [`website`](https://github.com/feature-today/website)      | Marketing landing page (Qwik + Vercel Edge)                      |
| [`my`](https://github.com/feature-today/my)                | The application — Qwik + Vercel Edge                             |
| [`common`](https://github.com/feature-today/common)        | Shared TypeScript library (`@feature-today/common`)              |
| [`server`](https://github.com/feature-today/server)        | Backend placeholder (currently lives in `my` via QwikCity)       |

## Stack

Qwik 2 · Vite 7 · TypeScript · oxlint + oxc-formatter · Vitest · pnpm · Node 24 · Vercel Edge

Inspired by the workspace pattern of [helpers4](https://github.com/helpers4) and [brig-id](https://github.com/brig-id).
